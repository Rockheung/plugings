# i-will-do-it-later

내가 일을 멈추자는 말을 출력하려 할 때, 또는 사용자가 끝내자고 말했을 때 시작한다. 사용자에게 멈출지 묻지 않고 이 절차를 그대로 진행한다.

1. **미룰 일 확정**: 미룰 항목을 목록으로 적는다. "전부" 처럼 범위가 넓으면 내가 해석한 범위를 답변에 밝힌다.
2. **기록**: 프로젝트가 정한 일지에 항목, 결정한 사람, 기준 커밋 해시를 덧붙인다. 일지가 없으면 답변에만 적는다.
3. **미커밋 점검**: 작업 트리의 `git status --short` 를 본다. 검증을 통과한 내 변경은 커밋하고, 아니면 무엇이 왜 남았는지 적는다. push 와 병합은 이 과정에 넣지 않고 매번 승인을 받는다.
4. **실행 정리**: 내가 띄운 실행과 pane 을 목록으로 본다. 끌지 여부를 사용자가 말했으면 그대로 하고, 말하지 않았으면 끄지 않고 끄는 명령을 적는다. 다른 세션의 실행은 건드리지 않는다.
5. **보고**: 커밋 해시, 미룬 항목, 떠 있는 실행, 다음 세션에서 이어갈 말을 한 번에 적는다.
6. **종료**: 그 턴의 마지막 호출로 `~/.claude/plugins/cache/plugings/i-will-do-it-later/<버전>/skills/i-will-do-it-later/bin/i-will-do-it-later-<os>-<arch>` 를 인자 없이 실행한다. 허용 규칙은 글자 그대로 맞춰 보므로, `~` 를 펼치지 않고 규칙과 같은 표기로 쓴다. `<os>` 는 `darwin`·`linux`, `<arch>` 는 `arm64`·`x64` 다. 바이너리는 자기 pane(`$HERDR_PANE_ID`)에 `/exit` 와 Enter 를 보내고, 세션은 호출이 끝나기 전에 끝난다. 그 턴의 응답은 대화 기록에 남지 않을 수 있으므로 보고를 호출 뒤로 미루지 않는다.

`i-will-do-it-later.ts` 는 어떤 경우에도 읽지 않는다.

세션 종료에 `EndConversation` 도구를 쓰지 않는다.

herdr 밖이거나 허용 규칙이 없으면 6단계가 실패한다. auto 모드 분류기는 허용 규칙이 없는 자기 pane 조작을 `Tmux Self Drive` 사유로 거부한다. 그때는 다른 명령으로 우회하지 않고, 사용자에게 `/exit` 입력을 안내한다.

시험할 때는 일회용 세션이 실제 일지에 쓰지 않도록 일지 경로를 따로 둔다.
